## The statement for every row marked **none**

The table marks a row **none** when no single `facts/*.md` line named that type, and this paragraph
is the statement for all of them, by kind:

* **A name the framework's interface prints under a qualified spelling.** The port writes it nested or
  qualified — `IntentPerson.Handle`, `AnyAppEntity`, `AnyRange`, `DateComponents`, `Float`, `FloatResolver`,
  `DateResolver`, `DateComponentsResolver`, `ElementResolver`, `IdentityResolver`, `IndexRecord`,
  `IntentDonation`, `IntentDonationStore`, `IntentChoiceRequest`, `IntentConfirmationRequest`,
  `Continuation`, `ContinuationError`, `Calendar.RecurrenceRule`, `IntentIndexRecord` and the rest of
  the dotted rows — and the interface prints the same type as
  `AppIntents::`‑qualified or nested in its own container. **The port is not inventing them; the
  subtraction in the script compares the unqualified name only**, and this is what the remaining
  dotted rows are.
* **An SDK type in a framework this band does not read.** `CLPlacemark` (CoreLocation),
  `CSSearchableItem` / `CSSearchableIndex` / `CSSearchableItemAttributeSet` (CoreSpotlight — lifted by
  `modules/apple/spotlight_lift.lua` and linked, see `Spotlight.md`), `ArrowEdge` and the other
  SwiftUI names (the SwiftUI band's package, not consumed here), `BundleDescription` (Foundation's
  bundle overlay, carried by the runtime). The port *names* these to use them; it declares none of them.
* **A protocol this band wrote because the framework's own machinery behind it is not here**:
  `CustomLocalizedStringResourceConvertible`, `EntityQueryComparatorProtocol`,
  `EntityQueryPropertyValue`, `AppShortcutParameterPresentationProtocol`, `IntentItemTextResolver` and its
  siblings — each is stated where it is defined (`Values.swift`, `Queries.swift`, `Parameter.swift`) and
  the reason each is needed is in the facts beside its file.
* **A support type of one of the framework's own declarations**: `ControlStyle`, `ControlWidgetDescriptionContext`,
  `AppShortcutOptionsCollectionSpecificationFor`, `AppShortcutParameterPresentationSnapshot`,
  `AppShortcutParameterPresentationTitleBuilder` — the value types the framework's initialisers take,
  spelled out here because the framework's own are gated on a type this release does not carry.

A name that none of those four covers is a name this band invented, and it is removed rather than
explained: the script's counts are printed by every run, so a new one shows up as a row whose *what it
is* is neither an SDK type nor a macro and whose stated-at column is **none**.
