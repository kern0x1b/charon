# Security: a decision per row, read one at a time

103 rows the registry recorded as absent/ignored/inert, and for each the reason it is not that.
The registry's four answers exist so a member of a class the port carries is CALLABLE:
`implemented` if it can act, `inert` - accepted, held, read back, with the effect stated - if
there is genuinely nothing on the release to act on, and `absent` only for API that cannot be
declared at all.

implemented 42   inert 59   stays absent pending a measurement 2

The TLS family is decided BY NAME and before any wording: 57 sec_protocol*, sec_protocol_metadata*
sec_identity*, sec_certificate_* and sec_trust_* accessors. 19 of them are worded as 'arrived in
iOS 13' rather than as the TLS sentence, and a first pass decided those as implemented - the wording
matched, the family did not. A first pass decided those 15 as implemented and that was wrong - the wording
matched, the family did not.
