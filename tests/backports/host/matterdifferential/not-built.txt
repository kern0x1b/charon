# matterdifferential/not-built.txt - the clusters this check cannot build against the host's Matter, and why.
#
# run.sh still builds each one. One that does not build is counted as skipped, and its reason is the one here; one
# that builds is STALE and fails the run until it is taken off this list. The count of entries is pinned by the light
# guard suite tests/addon/matter_skip_test.lua, so a cluster cannot leave the list, or join it, unseen.
#
# The host is the macOS SDK the check compiles against. The iOS 26.2 SDK declares both classes below; the macOS one does
# not, so there is no system class to compare the port's with. Measured on the host: `grep` of the macOS Matter headers
# finds no MTRBaseClusterTimer and no MTRGroupcastClusterExpireGracePeriodParams.
